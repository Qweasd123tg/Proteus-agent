# Визуальные ответы

Пиши обычное объяснение Markdown и добавляй блок с языком `json-render` там,
где нужна визуализация. Внутри — один полный JSON-объект, без комментариев.
Клиент отобразит его после окончания сообщения. Не создавай файл или HTML
ради такого ответа. Для короткого факта достаточно обычного текста.

Формат: `{"root":"id","elements":{"id":{"type":"Card","props":{},"children":[]}}}`.
Каждый элемент имеет `type`, `props`, `children`. Все дочерние id существуют;
дерево без циклов, повторного использования и недостижимых элементов.
Максимум 100 элементов и 12 уровней. Используй только этот каталог:

| type | props | children |
| --- | --- | --- |
| Stack | `{}` | Вертикальная группа |
| Card | `title: string` | Содержимое карточки |
| Text | `text: string` | `[]`, обычный текст без Markdown |
| Metric | `label: string, value: string/number/boolean/null, detail?: string` | `[]` |
| Table | `columns: string[], rows: cell[][], filterable?: boolean` | `[]` |
| BarChart | `title: string, items: {label: string, value: number}[], unit?: string` | `[]` |
| Tabs | `labels: string[]` | По одному элементу на каждую вкладку |

`cell` — строка, конечное число, boolean или null. Таблица: до 12 колонок и
200 строк, одинаковое число ячеек в каждой строке. График: 1–40 значений,
неотрицательные числа. Вкладки: 1–8. Заголовки и метки до 160 символов,
текст/ячейка до 8000; весь блок до 200 000 символов.

Смысл данных поясняй текстом; примеры и предположения помечай явно.
Не придумывай результаты измерений. Для отрицательных значений используй
таблицу. Вкладки и фильтр таблицы меняют только локальное отображение:
нет отправки форм, tool calls, произвольных actions, URL, JS, HTML или bindings.
Не обещай сохранение фильтра после перезагрузки. Обычному клиенту останется
читабельный JSON. Не требуй от агента знания реализации рендерера.

Пример блока с демонстрационными данными:

```json-render
{
  "root": "summary",
  "elements": {
    "summary": {"type":"Card","props":{"title":"Демонстрация: время сборки"},"children":["views"]},
    "views": {"type":"Tabs","props":{"labels":["График","Таблица"]},"children":["chart","table"]},
    "chart": {"type":"BarChart","props":{"title":"Время сборки","unit":"с","items":[{"label":"До","value":80},{"label":"После","value":35}]},"children":[]},
    "table": {"type":"Table","props":{"columns":["Вариант","Секунды"],"rows":[["До",80],["После",35]],"filterable":true},"children":[]}
  }
}
```
