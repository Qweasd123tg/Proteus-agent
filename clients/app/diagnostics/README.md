# Встроенная Диагностика

Внутренний пакет `proteus-app-diagnostics` основного приложения. Он содержит
работающие экраны расхода, анализа, настройки сборки и архитектуры. Расширения
настроек встраивают его страницу `inspector.html` с подключением родительского
окна. Все функции постепенно переносятся в расширения интерфейса.

Этот пакет собирается вместе с приложением через `scripts/desktop.sh`.
Подробности: [приложение](../../../docs/guides/desktop.md),
[расширения интерфейса](../../../docs/guides/ui-extensions.md).

Текущий состав:

- `?view=usage` — подробный отчёт расхода и снимок контекста. Читает `/sessions`,
  `/usage` и `/context` по явному `session_dir`, не возобновляет сессию.
  Выбор анализируемой сессии независим от чата, сохраняется в URL;
  «Открыть диалог» открывает именно выбранную сессию. Фильтры, стоимость и
  JSON-выгрузка используют общий renderer расширения расхода.

- `/analysis` читает `/sessions` и `/analysis`: выбор сохранённого хода,
  итог и ошибка, историческая конфигурация, шаги модели/инструментов/сжатия,
  поиск и фильтр проблемных шагов. Подробности показывают сохранённый
  canonical-запрос, ответ и расход токенов. Просмотр не возобновляет сессию;
  обновление снимка выполняется кнопкой. Выбор хранится в URL.

- `/configs` читает `/config` и `/config/builder`. Краткая сводка показывает
  сохранённую сборку; выбор модели и режима подтверждений находится над
  вкладками «Модули», «Инструменты» и «Детали».
- В модулях доступен поиск, выбор реализации и сворачиваемые параметры.
  Форма и JSON редактируют один черновик; переключение реализации сохраняет
  её введённые параметры. Ошибочные значения блокируют сохранение.
- В инструментах доступны поиск по имени и описанию, фильтр включённых и
  чекбоксы `tools.enabled`. Не зарегистрированный инструмент, оставшийся
  в конфигурации, можно отключить.
- В «Деталях» находятся рабочий каталог, параметры рассуждения модели,
  компоненты и файлы профиля.
- Панель сохранения показывает состояние черновика и путь целевого файла.
  «Сбросить» возвращает сохранённые значения; обновление недоступно при
  несохранённых изменениях. Во время сохранения редактирование и повторная
  отправка заблокированы. Запись выполняется через `POST /config/builder`.
- `/architecture` строит интерактивную SVG-карту из `/inspect/topology`:
  выбор узлов, связи, поиск, слоты, модули, инструменты и предупреждения.
  Карта поддерживает pan/zoom, автоматический `fit` и полноэкранный режим с
  выходом по `Escape`. `/inspect/topology.mmd` читается по кнопке экспорта Mermaid.
- До загрузки диагностических экранов выбирает одну сессию окна: сначала из
  `session_dir` в URL, затем из `sessionStorage` для точного app-server origin,
  затем из `/bootstrap`. Выбор подтверждается через `/resume`; если сессий ещё
  нет, диагностика создаёт её через `/new-session`. Все config/inspect запросы
  содержат явный `session_dir`.

## Ответственность

Пакет использует публичные DTO из `proteus-contracts::app_protocol` и общие
правила подключения из `../common`. Config builder записывает выбранную модель,
права, модули агента и инструменты через `POST /config/builder`.
Renderer карты находится в `graph/` и поставляется локально.
