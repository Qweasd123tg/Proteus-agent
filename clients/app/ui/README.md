# Интерфейс Приложения

Чат, рабочая область, настройки и расширения основного приложения Proteus.
Пакет `proteus-app-ui` собирается в WASM через Trunk; его ресурсы входят
в переносимое приложение. Общий запуск и сборка — `scripts/desktop.sh`
из корня репозитория.

- `src/` — Leptos-представления, состояние и HTTP/SSE API.
- `ui/` — оформление, навигация, размещение и встроенные расширения.
- `extensions/` — загрузчик, публичный контракт и поставляемые панели.
- `rendering/` — локальные зависимости Markdown и интерактивных ответов.
- `tests/` — проверки интерфейса, расширений и браузерные/WebKit стенды.

API и DTO импортируются из `proteus-contracts::app_protocol`; общие правила
подключения и сессий — из `../common`. Модули агента остаются за API сервера.

Руководства: [приложение](../../../docs/guides/desktop.md),
[расширения интерфейса](../../../docs/guides/ui-extensions.md).
