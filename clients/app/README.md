# Приложение Proteus

Единый пользовательский клиент на Tauri и Leptos.

| Каталог | Ответственность |
|---|---|
| `ui/` | Чат, рабочая область, настройки и расширения интерфейса |
| `diagnostics/` | Встроенные экраны расхода, анализа, сборки и архитектуры |
| `common/` | Общие правила подключения, ответов и выбора сессии |
| `src-tauri/` | Нативное окно, выбор проекта и управление сервером |
| `launcher/` | Форма выбора проекта и оформление окна |
| `scripts/` | Подготовка ресурсов, упаковка и проверка приложения |

Из корня репозитория:

```bash
./scripts/desktop.sh dev
./scripts/desktop.sh build
./clients/app/build/Proteus/proteus-desktop
```

Полное [руководство](../../docs/guides/desktop.md) и
[контракт расширений интерфейса](../../docs/guides/ui-extensions.md).
Диагностические функции постепенно переносятся в самостоятельные расширения;
текущие работающие экраны сохраняются внутри приложения.
